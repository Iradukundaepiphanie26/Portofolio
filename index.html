Horizon Transportation Ticket Booking System

Built using Eclipse/NetBeans IDEs, PHP backend scripts, MySQL relational databases, and CSS/HTML layouts.

booking_process.php (Sample PHP Backend Script) 
<?php
// Database connection for Horizon Ticket System
$conn = new mysqli("localhost", "root", "", "horizon_tickets");

if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}

// Process ticket reservation
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $passenger_name = mysqli_real_escape_string($conn, $_POST['fullname']);
    $destination = mysqli_real_escape_string($conn, $_POST['destination']);
    $travel_date = $_POST['travel_date'];

    $sql = "INSERT INTO bookings (passenger_name, destination, travel_date, status) 
            VALUES ('$passenger_name', '$destination', '$travel_date', 'CONFIRMED')";

    if ($conn->query($sql) === TRUE) {
        echo json_encode(["status" => "success", "message" => "Ticket booked successfully!"]);
    } else {
        echo json_encode(["status" => "error", "message" => $conn->error]);
    }
}
?>

Graduation Readiness Forecasting System

System Overview

Data science project developed using Python in Anaconda Jupyter Notebooks to verify if students meet graduation criteria based on marks and attendance percentages.

Key Features

  • Computes mean, median, and variance across student cohorts.
  • Generates Correlation Heatmaps to evaluate mark-attendance relationship.
  • Automates eligibility categorization into Ready vs. Pending.
graduation_analysis.py (Python Pandas Snippet) 
import pandas as pd
import seaborn as sns
import matplotlib.pyplot as plt

# Load student records dataset
df = pd.read_csv('student_academic_records.csv')

# Compute statistical eligibility score
df['Eligibility_Score'] = (df['Average_Mark'] * 0.7) + (df['Attendance_Rate'] * 0.3)
df['Graduation_Ready'] = df['Eligibility_Score'].apply(lambda x: 'READY' if x >= 60 else 'NOT_READY')

# Output correlation heatmap
plt.figure(figsize=(8,5))
sns.heatmap(df[['Average_Mark', 'Attendance_Rate', 'Eligibility_Score']].corr(), annot=True, cmap='viridis')
plt.title('Academic Features Correlation Matrix')
plt.show()

print("Graduation Ready Students Count:", len(df[df['Graduation_Ready'] == 'READY']))
